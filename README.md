# 司量 Siliang

> 一款 macOS 原生的个人记账与生活管理应用 —— 割り勘（AA 记账）、积分记录、物品使用周期、AI Token 消耗统计,一个应用全搞定。

**司量（Siliang）** 是一个用 SwiftUI 打造的 macOS 个人工具,把日常最容易漏记的几类账目集中管理:和朋友吃饭的 AA 分摊、积分计划的获得与消耗、订阅/物品的使用周期、大模型 API 的 Token 消耗。所有数据本地保存,界面中/日双语,支持通过同步文件夹在多台设备间同步。

## ✨ 功能总览

### 💴 割り勘(AA 记账)
- **记一笔**:支持收入 / 支出两个方向,总额可自定义
- **分摊方式**:均分,或为每人指定自定义金额(总额校验)
- **成员库**:成员从下拉选择,不允许随意输入
- **自动结算**:自动计算「谁该付谁多少」,按最少转账给出方案
- **登记还款**:记录谁还了谁,自动计算「还差多少」净账
- **收支日历**:月历格子直接显示当天收入(+) / 支出(−)金额,带当月合计
- **结算汇总置顶展示**,不会被日历遮挡

### ⭐ 积分记录
- 记一笔:获得 / 消耗两个方向
- **延迟到账**(付与予定):支持 pending + 预计日期,不计入余额、单独高亮展示
- 账户余额面板:按积分计划分组查看余额 + 待入账

### 📦 物品使用
- 记一件物品:名称、分类、开始时间
- 使用状态:使用中 / 已结束(结束时间必填、使用中禁用)
- **区间热力图**:全年展示每个物品的使用周期,使用中的自动延伸到今天

### 🤖 Token 使用(LLM 消耗统计)
- 记一笔:应用场景(必填)、模型(必填)、API Key(可隐藏,默认只显示末 4 位)、日期、输入/输出 tokens、费用
- **按应用场景分组统计**,卡片展示各场景的模型与消耗
- 年度热力图,可按场景筛选

### 🔐 登录与管理员
- 首次启动创建管理员账号,并展示 + 保存**恢复密钥**
- 普通登录(用户名 + 密码),登录态持久化
- 「忘记密码?」→ 凭恢复密钥重置
- 管理员页:用户管理(增 / 删、角色切换、改密码)、恢复密钥(查看 / 复制 / 重新生成)

### ⚙️ 设置与本地化
- 语言切换:中文 / 日本語(数据格式固定 ja-JP)
- 数据本地保存,**同步文件夹**跨设备同步(LWW 合并 + 墓碑删除)

## 🚀 安装与使用

### 方式一:直接运行(推荐)

1. 从 [Releases](https://github.com/67-qingshui/Siliang/releases) 下载 `Siliang.dmg`
   - 最新版:[下载 v1.0.0](https://github.com/67-qingshui/Siliang/releases/download/v1.0.0/Siliang.dmg)
2. 双击打开,把 `Siliang.app` 拖入「应用程序」
3. 首次启动按引导创建管理员账号,**务必保存恢复密钥**(忘记密码时靠它找回)

> 由于未进行 Apple 公证,首次打开若提示「无法验证开发者」,请在「系统设置 → 隐私与安全性」中点击「仍要打开」。

### 方式二:源码构建

需要 macOS 14+ 与 Swift 5.9+:

```bash
# 构建 debug 版
swift build

# 构建并打包 dmg
./script/package.sh
```

打包产物输出到 `dist/Siliang.dmg`。

## 🔧 技术要点

- **纯 SwiftUI**,无第三方依赖,SwiftPM 管理
- **数据层**:JSON 文件本地持久化(`~/Library/Application Support/Siliang/`),`AppStore` 作为全局状态中枢
- **结算引擎**:先做净额抵消(应收 - 应付),再求最少转账方案,避免 A→B→C 的冗余转账
- **同步设计**:同步文件夹 + LWW(最后写入胜出)合并 + 墓碑(tombstone)删除,记录级 `updatedAt` 时间戳
- **安全**:密码使用加盐哈希存储;恢复密钥为随机生成的 32 位十六进制串,仅展示一次
- **i18n**:枚举化文案 + 中/日双字典,`ja-JP` 作为稳定数据格式
